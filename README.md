# Virtual Dice

A simple, fast, and offline dice roller and session tracker for Android. Built for tabletop games, RPGs, and board game nights like Catan.

## Features

- **Dice rolling**: Roll 1 to 10+ dice at once. Supports standard tabletop dice (d4, d6, d8, d10, d12, d20) as well as custom dice up to 1000 sides.
- **Custom dice styling**: Customize colors for individual dice and their numbers/pips.
- **Mirror Result**: Flips the roll total upside-down for players sitting across the table so everyone can read the result easily.
- **Catan mode**: Turn tracker for 3–6 players with custom player names, "7" robber alerts with haptics, and an Undo Roll button.
- **Roll history & stats**: Track previous rolls, view total distributions and averages, and save game sessions.
- **Fair Dice**: Optional mode that balances roll totals over time while maintaining real dice probabilities.
- **Themes & Dark Mode**: 5 built-in themes (Plum, Ocean, Forest, Sunset, Amber) plus a custom color picker and dark mode.
- **Haptics & sound**: Multiple dice roll animations, sound effects, and vibration feedback.
- **100% Offline**: Works completely offline. No ads, no account required, and no tracking.
